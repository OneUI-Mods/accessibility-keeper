# Accessibility Keeper

[日本語](README.md) · [English](README.en.md)

アプリを強制終了しても、そのアプリのユーザー補助の許可が外れないようにするVector / Xposedモジュールです。Android 17、libxposed API 102に対応します。

## できること

- 強制終了したアプリのユーザー補助サービスを、有効な一覧から消さずに保ちます。ユーザー補助のショートカットもそのまま残ります。
- 強制終了したあとの動作を選べます。
  - **次にアプリを開くまで待つ**（初期設定）：アプリを開いた時点で再開します。待っている間、設定では「動作していません」と表示されることがあります。
  - **すぐに再接続する**：ユーザー補助サービスがすぐに起動し直します。
- ユーザー補助を持つアプリを一覧で表示し、アプリごとにON/OFFできます。初期設定ではすべてONです。
- Vectorのホット更新に対応します。更新時に端末やシステムを再起動しません。

アプリそのものの強制終了（プロセスの終了）は、これまでどおり行われます。

## 対応環境

- 動作確認済み：Galaxy S26 Ultra（SM-S948Q）、Android 17 / One UI 9（BZI9）
- Vector（libxposed API 102）

## 使い方

1. 署名済みAPKをインストールします。
2. VectorでAccessibility Keeperを有効にします。対象は「システムフレームワーク」です。
3. 初回だけ端末を再起動します。以後の更新はホット更新で反映されます。
4. アプリを開き、強制終了したあとの動作と、対象にするアプリを選びます。

## 制限

- 端末の再起動直後、最初の起動までに強制終了したアプリは対象になりません。
- 待っている間のサービスは、設定画面で「動作していません」と表示されることがあります。
