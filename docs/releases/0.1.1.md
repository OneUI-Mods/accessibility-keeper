# Accessibility Keeper 0.1.1

初版です。アプリを強制終了しても、そのアプリのユーザー補助の許可が外れないようにします。強制終了したあとは、次にアプリを開くまで待つ（初期設定）か、すぐに再接続するかを選べます。ユーザー補助を持つアプリごとにON/OFFでき、初期設定ではすべてONです。

署名済みAPKをインストールし、VectorでシステムフレームワークをONにしたうえで、初回だけ端末を再起動してください。

First release. Keeps an app's accessibility permission when the app is force stopped. After a force stop, the service either waits until the app is opened again (default) or reconnects right away. Each app that offers accessibility can be turned on or off; all are on by default.

Install the signed APK, enable it for System Framework in Vector, and restart the device once.
